# Settings Window - Окно настроек

## Обзор

Окно настроек предоставляет полный интерфейс для конфигурации всех аспектов приложения ClipStack. Доступно через меню "Settings" в menu bar или горячую клавишу `⌘,`.

## Структура окна

Окно настроек использует табированный интерфейс с 6 основными разделами:

### 1. General (Общие настройки)

#### Buffer Mode (Режим буфера)
- **Stack (LIFO)**: Последний добавленный элемент используется первым
- **Queue (FIFO)**: Первый добавленный элемент используется первым

#### Max Buffer Size (Максимальный размер буфера)
- Слайдер для выбора количества элементов (1-100)
- Текущее значение отображается рядом со слайдером

#### Notifications (Уведомления)
- Включить/выключить уведомления при копировании

#### Launch at Login (Запуск при входе)
- Автоматический запуск приложения при входе в систему

### 2. Hotkeys (Горячие клавиши)

Отображение всех настроенных горячих клавиш:

| Горячая клавиша | Описание |
|----------------|----------|
| `⌘⇧V` | Открыть окно предпросмотра |
| `⌘⇧C` | Очистить буфер обмена |
| `⌘⇧1-9` | Быстрая вставка элемента |
| `⌘⇧←/→` | Навигация по элементам |
| `⌘,` | Открыть настройки |

*Примечание: Изменение горячих клавиш будет доступно в будущих версиях*

### 3. Security (Безопасность)

#### Security Filter (Фильтр безопасности)
- Включить/выключить фильтрацию чувствительных данных

#### Protected Patterns (Защищённые паттерны)
Отображение списка защищённых паттернов:
- Пароли (password, passwd, pwd)
- Ключи API (api_key, apikey, secret)
- Токены (token, access_token)
- Кредитные карты (visa, mastercard, amex)
- Email адреса
- Номера телефонов

### 4. Blacklist (Чёрный список)

#### Enable Blacklist (Включить чёрный список)
- Активировать фильтрацию по чёрному списку

#### Preset Rules (Предустановленные правила)
- **Passwords**: Блокировать пароли
- **Emails**: Блокировать email адреса
- **Phone Numbers**: Блокировать номера телефонов
- **Credit Cards**: Блокировать номера кредитных карт
- **API Keys**: Блокировать ключи API
- **URLs**: Блокировать URL адреса
- **Custom**: Пользовательские правила

### 5. Auto-Clear (Автоочистка)

#### Enable Auto-Clear (Включить автоочистку)
- Активировать автоматическую очистку буфера

#### Presets (Предустановки)
- **Never**: Никогда не очищать
- **On Exit**: При выходе из приложения
- **Hourly**: Каждый час
- **Daily**: Каждый день
- **Weekly**: Каждую неделю
- **Custom**: Пользовательские настройки

#### Options (Опции)
- **Clear on app exit**: Очищать при выходе
- **Clear after inactivity**: Очищать после бездействия
- **Inactivity timeout**: Таймаут бездействия (5-60 минут)

### 6. About (О приложении)

#### Application Information
- **Version**: Версия приложения
- **Build**: Номер сборки
- **Swift Version**: Версия Swift
- **macOS Version**: Версия macOS

#### Links
- **GitHub**: Ссылка на репозиторий проекта
- **Documentation**: Ссылка на документацию
- **Report Issue**: Сообщить о проблеме

## Техническая реализация

### Архитектура

```
SettingsWindowController
├── NSWindowController
├── NSHostingView<SettingsView>
└── SettingsView (SwiftUI)
    ├── TabView
    ├── GeneralSettingsView
    ├── HotkeysSettingsView
    ├── SecuritySettingsView
    ├── BlacklistSettingsView
    ├── AutoClearSettingsView
    └── AboutView
```

### Ключевые компоненты

#### SettingsWindowController
- Управляет жизненным циклом окна настроек
- Интегрирует SwiftUI в AppKit через NSHostingView
- Обеспечивает правильное позиционирование и размер окна

#### SettingsView
- Основной SwiftUI view с табированным интерфейсом
- Использует SettingsManager для получения и сохранения настроек
- Реагирует на изменения настроек в реальном времени

#### SettingsManager Integration
- Все настройки сохраняются через UserDefaults
- Поддерживает экспорт/импорт настроек
- Обеспечивает согласованность данных между компонентами

### State Management

```swift
@State private var bufferMode: BufferMode = .stack
@State private var maxBufferSize: Int = 20
@State private var enableNotifications: Bool = true
@State private var launchAtLogin: Bool = false
```

Каждая настройка использует `@State` с `onChange` для синхронизации с `SettingsManager`.

### Reusable Components

#### HotkeyRow
Отображение информации о горячей клавише:
- Иконка функции
- Горячая клавиша
- Описание

#### PatternRow
Отображение защищённого паттерна:
- Название паттерна
- Регулярное выражение

#### PresetRow
Отображение предустановки:
- Название
- Описание
- Статус включения

## Использование

### Открытие окна настроек
1. Через menu bar: ClipStack → Settings
2. Через горячую клавишу: `⌘,`
3. Программно: `SettingsWindowController.shared.show()`

### Сохранение настроек
Настройки сохраняются автоматически при изменении:
- Слайдеры и переключатели сохраняются немедленно
- Сложные настройки сохраняются при закрытии окна

### Сброс настроек
Сброс к настройкам по умолчанию доступен через:
- Кнопку "Reset to Defaults" в каждой секции
- Полный сброс через меню "Reset All Settings"

## Устранение неполадок

### Частые проблемы

1. **Окно не открывается**
   - Проверьте права доступа в System Settings
   - Перезапустите приложение

2. **Настройки не сохраняются**
   - Проверьте доступ к UserDefaults
   - Убедитесь в отсутствии конфликтов с другими приложениями

3. **Горячие клавиши не работают**
   - Проверьте права Accessibility
   - Убедитесь в отсутствии конфликтов с системными горячими клавишами
