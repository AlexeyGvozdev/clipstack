# 📋 ClipStack

> Умный менеджер буфера обмена для macOS с поддержкой режимов Stack и Queue

[![macOS](https://img.shields.io/badge/macOS-12.0+-blue.svg)](https://www.apple.com/macos/)
[![Swift](https://img.shields.io/badge/Swift-5.9+-orange.svg)](https://swift.org/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

## 🎯 Что это?

ClipStack - это нативное macOS приложение, которое превращает стандартный буфер обмена в мощный инструмент для работы с множественными копированиями. Вместо того чтобы хранить только последнее скопированное значение, ClipStack накапливает все ваши копирования и позволяет извлекать их в нужном порядке.

### Ключевые особенности

- 🔄 **Два режима работы**: Stack (LIFO) и Queue (FIFO)
- ⌨️ **Горячие клавиши**: Быстрый доступ без отрыва от клавиатуры
- 🎨 **Минималистичный UI**: Иконка в menu bar с превью
- 🚫 **Чёрный список**: Фильтрация нежелательных копирований по подстрокам
- ⏱️ **Автоочистка**: Автоматическое удаление буфера по таймеру
- 🔒 **Приватность**: Все данные хранятся локально
- ⚡ **Производительность**: Нативный Swift, < 50MB памяти
- 🆓 **Open Source**: MIT лицензия

## 💡 Как использовать

### Режим Stack (LIFO - Last In, First Out)

Идеально для рефакторинга кода и перестановки блоков текста.

```
Копируете:  A → B → C
Вставляете: C → B → A
```

**Пример использования:**
1. Копируете старое имя переменной: `oldName`
2. Копируете новое имя: `newName`
3. Нажимаете `Cmd+Shift+V` → вставляется `newName`
4. Нажимаете `Cmd+Shift+V` → вставляется `newName` снова
5. Нажимаете `Cmd+Shift+B` → вставляется `oldName`

### Режим Queue (FIFO - First In, First Out)

Идеально для заполнения форм и последовательного ввода данных.

```
Копируете:  A → B → C
Вставляете: A → B → C
```

**Пример использования:**
1. Копируете имя: `Иван`
2. Копируете фамилию: `Петров`
3. Копируете email: `ivan@example.com`
4. Открываете форму
5. `Cmd+Shift+V` → `Иван`
6. `Cmd+Shift+V` → `Петров`
7. `Cmd+Shift+V` → `ivan@example.com`

## ⌨️ Горячие клавиши

| Действие | Комбинация | Описание |
|----------|------------|----------|
| Извлечь первый | `Cmd+Shift+V` | Вставляет элемент из начала буфера |
| Извлечь последний | `Cmd+Shift+B` | Вставляет элемент с конца буфера |
| Переключить режим | `Cmd+Shift+M` | Stack ↔ Queue |
| Показать буфер | `Cmd+Shift+C` | Открывает окно предпросмотра |
| Очистить буфер | `Cmd+Shift+X` | Удаляет все элементы |

## ⏱️ Автоматическая очистка

Настройте автоматическую очистку буфера через заданный интервал времени:

**Доступные интервалы:**
- 5 минут
- 15 минут
- 30 минут (по умолчанию)
- 1 час
- 2 часа
- 4 часа
- Никогда

**Дополнительные опции:**
- ✅ Уведомление перед очисткой
- ✅ Сброс таймера при копировании
- ✅ Очистка только старых элементов
- ✅ Отложить очистку на 10 минут

**Пример:**
```
Настройка: Очистка через 30 минут

09:00 - Начали работу, копируете данные
09:15 - Буфер содержит 10 элементов
09:29 - Уведомление: "Буфер будет очищен через 60 секунд"
09:30 - Автоматическая очистка! Буфер пуст
```

> 💡 Все горячие клавиши можно настроить в Settings

## 🔒 Безопасность и фильтрация

### Автоматическая фильтрация чувствительных данных

ClipStack автоматически блокирует:

- ❌ Пароли (паттерны `password:`, `pwd:`)
- ❌ Номера кредитных карт
- ❌ API ключи и токены
- ❌ SSH/GPG приватные ключи

### Чёрный список (Blacklist)

Настраиваемая фильтрация по подстрокам. Если скопированный текст содержит любую подстроку из чёрного списка, он не будет добавлен в буфер.

**Примеры использования:**

```
Чёрный список: ["localhost", "tmp", "CONFIDENTIAL"]

✅ "https://example.com" → добавляется
❌ "http://localhost:3000" → блокируется (содержит "localhost")
❌ "tmp_file.txt" → блокируется (содержит "tmp")
❌ "CONFIDENTIAL: Project" → блокируется (содержит "CONFIDENTIAL")
```

**Настройка:**
- Settings → Blacklist
- Добавить/удалить правила
- Включить/выключить отдельные правила
- Настроить чувствительность к регистру
- Использовать готовые пресеты

Все данные хранятся локально и никогда не отправляются в интернет.
