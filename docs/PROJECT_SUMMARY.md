## 🎯 Проблема

При работе с множеством данных пользователи часто копируют несколько значений подряд, но стандартный буфер обмена macOS хранит только **последнее** скопированное значение. Это приводит к:

- ❌ Постоянному переключению между источником и местом назначения
- ❌ Потере времени на повторное копирование
- ❌ Снижению продуктивности при рефакторинге кода
- ❌ Неудобству при заполнении форм

## 💡 Решение

**ClipStack** - умный менеджер буфера обмена, который:

- ✅ Перехватывает все операции копирования (Cmd+C)
- ✅ Накапливает до 100 элементов в буфере
- ✅ Предоставляет два режима извлечения: Stack (LIFO) и Queue (FIFO)
- ✅ Позволяет извлекать значения через горячие клавиши
- ✅ Фильтрует чувствительные данные (пароли, ключи)
- ✅ Настраиваемый чёрный список для блокировки по подстрокам
- ✅ Автоматическая очистка буфера по таймеру

## 🎨 Ключевые особенности

### 1. Два режима работы

#### Stack (LIFO - Last In, First Out)
```
Копирование:  A → B → C
Извлечение:   C → B → A
```
**Применение**: Рефакторинг кода, перестановка блоков

#### Queue (FIFO - First In, First Out)
```
Копирование:  A → B → C
Извлечение:   A → B → C
```
**Применение**: Заполнение форм, последовательный ввод

### 2. Горячие клавиши

| Действие | Комбинация |
|----------|------------|
| Извлечь первый | `Cmd+Shift+V` |
| Извлечь последний | `Cmd+Shift+B` |
| Переключить режим | `Cmd+Shift+M` |
| Показать буфер | `Cmd+Shift+C` |
| Очистить буфер | `Cmd+Shift+X` |

### 3. Безопасность и фильтрация

**Автоматическая фильтрация чувствительных данных:**
- Паролей
- Номеров кредитных карт
- API ключей и токенов
- SSH/GPG приватных ключей

**Чёрный список (Blacklist):**
- Настраиваемые правила фильтрации по подстрокам
- Поддержка case-sensitive/insensitive поиска
- Готовые пресеты (разработка, конфиденциальность, временные файлы)
- Статистика блокировок
- Импорт/экспорт правил

**Примеры использования чёрного списка:**
```
Правило: "localhost"
✅ "https://example.com" → добавляется
❌ "http://localhost:3000" → блокируется

Правило: "CONFIDENTIAL" (case-sensitive)
✅ "confidential notes" → добавляется
❌ "CONFIDENTIAL: Project" → блокируется
```

### 4. Автоматическая очистка (Auto-Clear)

**Настраиваемая очистка по таймеру:**
- Интервалы: 5, 15, 30 минут, 1, 2, 4 часа
- Уведомление перед очисткой
- Сброс таймера при активности
- Режим "только старые элементы"
- Возможность отложить очистку

**Примеры использования:**
```
Настройка: Очистка через 30 минут

09:00 - Начали работу, копируете данные
09:15 - Буфер содержит 10 элементов
09:29 - Уведомление: "Буфер будет очищен через 60 с"
09:30 - Автоматическая очистка! Буфер пуст
```

**Режимы:**
- **Полная очистка**: Удаляет весь буфер
- **Только старые**: Удаляет элементы старше N минут
- **С уведомлением**: Предупреждает перед очисткой
- **Тихая**: Очищает без уведомлений

### Основные компоненты

```
┌─────────────────────────────────────┐
│         User Interface              │
│  (Menu Bar + Preview Window)        │
└──────────────┬──────────────────────┘
               │
┌──────────────▼──────────────────────┐
│      Application Layer              │
│  (Coordinator + Managers)           │
└──────────────┬──────────────────────┘
               │
┌──────────────▼──────────────────────┐
│       Business Logic                │
│  (Buffer + Security + Blacklist +   │

└──────────────┬──────────────────────┘
               │
```

- **UI**: SwiftUI + AppKit

- **Storage**: Core Data + UserDefaults
- **Security**: Regex patterns + Blacklist rules
- **Notifications**: UserNotifications
