# ClipStack - Быстрый старт

## 🎯 Что такое ClipStack?

**ClipStack** - это умный менеджер буфера обмена для macOS, который позволяет накапливать несколько скопированных значений и извлекать их в нужном порядке.

### Ключевая идея

Вместо одного значения в буфере обмена → **до 100 значений** с двумя режимами работы:
- **Stack (LIFO)**: последний скопированный → первый вставляется
- **Queue (FIFO)**: первый скопированный → первый вставляется

## ⚡ Быстрый пример

### Сценарий: Рефакторинг кода (Stack режим)

```
1. Копируете: oldVariableName
2. Копируете: newVariableName
3. Находите место использования
4. Cmd+Shift+V → вставляется newVariableName ✨
5. Находите следующее место
6. Cmd+Shift+V → вставляется newVariableName ✨
7. Нужно старое имя?
8. Cmd+Shift+B → вставляется oldVariableName ✨
```

### Сценарий: Заполнение формы (Queue режим)

```
1. Копируете из документа: "Иван"
2. Копируете: "Петров"
3. Копируете: "ivan@example.com"
4. Открываете форму
5. Cmd+Shift+V → "Иван" ✨
6. Tab, Cmd+Shift+V → "Петров" ✨
7. Tab, Cmd+Shift+V → "ivan@example.com" ✨
```

## ⌨️ Горячие клавиши (по умолчанию)

| Клавиши | Действие |
|---------|----------|
| `Cmd+Shift+V` | Извлечь первый элемент |
| `Cmd+Shift+B` | Извлечь последний элемент |
| `Cmd+Shift+M` | Переключить Stack ↔ Queue |
| `Cmd+Shift+C` | Показать окно буфера |
| `Cmd+Shift+X` | Очистить весь буфер |

## 🔧 Первоначальная настройка

### 1. Разрешения системы

При первом запуске macOS попросит разрешения:

```
System Preferences → Security & Privacy → Privacy
→ Accessibility → ✅ ClipStack
```

**Зачем нужно**: Для перехвата горячих клавиш и симуляции вставки

### 2. Выбор режима по умолчанию

При первом запуске выберите режим:
- **Stack** - для разработчиков, рефакторинга
- **Queue** - для заполнения форм, последовательного ввода

💡 Режим можно переключить в любой момент через `Cmd+Shift+M`

### 3. Настройка горячих клавиш (опционально)

```
Menu Bar → ClipStack → Settings → Hotkeys
```

Измените комбинации, если они конфликтуют с другими приложениями.

## 📖 Основные концепции

### Режим Stack (LIFO)

```
Копирование:  A → B → C → D
               ↓   ↓   ↓   ↓
Буфер:        [D, C, B, A]
               ↑
Cmd+Shift+V:  D (извлекается и удаляется)
Cmd+Shift+V:  C (извлекается и удаляется)
Cmd+Shift+B:  A (извлекается с конца)
```

**Когда использовать**:
- ✅ Рефакторинг кода
- ✅ Перестановка блоков текста
- ✅ Работа с вложенными структурами

### Режим Queue (FIFO)

```
Копирование:  A → B → C → D
               ↓   ↓   ↓   ↓
Буфер:        [A, B, C, D]
               ↑
Cmd+Shift+V:  A (извлекается и удаляется)
Cmd+Shift+V:  B (извлекается и удаляется)
Cmd+Shift+B:  D (извлекается с конца)
```

**Когда использовать**:
- ✅ Заполнение форм
- ✅ Последовательный ввод данных
- ✅ Копирование списков

## 🔒 Безопасность

ClipStack автоматически **НЕ сохраняет**:
- ❌ Пароли (паттерны `password:`, `pwd:`)
- ❌ Номера кредитных карт
- ❌ API ключи и токены
- ❌ SSH/GPG приватные ключи

При попытке скопировать чувствительные данные появится уведомление.

## 💡 Советы и трюки

### 1. Быстрое переключение режимов
```
Работаете с кодом → Stack режим (Cmd+Shift+M)
Заполняете форму → Queue режим (Cmd+Shift+M)
```

### 2. Предпросмотр перед вставкой
```
Cmd+Shift+C → откроется окно
Посмотрите что в буфере
ESC → закрыть
Cmd+Shift+V → вставить
```

### 3. Очистка буфера
```
Закончили задачу → Cmd+Shift+X
Буфер очищен, готов к новой задаче
```

### 4. Работа с длинными текстами
```
В окне буфера (Cmd+Shift+C):
- Клик на элемент → показать полный текст
- Двойной клик → скопировать обратно
- Правый клик → контекстное меню
```

## 🐛 Решение проблем

### Горячие клавиши не работают

1. Проверьте разрешения:
   ```
   System Preferences → Security & Privacy → Privacy
   → Accessibility → ✅ ClipStack
   ```

2. Перезапустите приложение:
   ```
   Menu Bar → ClipStack → Quit
   Запустите снова из Applications
   ```

### Буфер не сохраняет элементы

1. Проверьте, что копируете текст (не изображения)
2. Проверьте, что не копируете чувствительные данные
3. Проверьте лимит буфера в Settings (по умолчанию 100)

### Конфликт горячих клавиш

1. Откройте Settings → Hotkeys
2. Измените конфликтующие комбинации
3. Сохраните и перезапустите
